# Source pack: the old irahospitality.co.in

This is the research capture of the previous live site, taken on 12 Nov 2026. It is the **source of truth for content, colours and fonts**.

| File | What it is |
|---|---|
| `source-pack.md` | Every page's copy (verbatim, mistakes included), sitemap, all 28 job texts, the asset table, design tokens (colours, type, buttons, motion), SEO tags, form fields and validation, and the known issues of the old site |
| `screenshots/desktop/` | 27 slices of the old site at 1440 px |
| `screenshots/mobile/` | 19 slices at 390 px |
| `images-manifest.csv` | Each image's file name and its original URL on the old site |

**The original images are not duplicated here.** The 54 files listed in the manifest live in `src/assets/img/` under the same names and are byte-identical to the downloads. Nothing exists at a higher resolution on the old server.

Not available anywhere (do not invent):
- Feu project images (404 on the old server)
- A vector or high-resolution logo
- Real quotes for 3 of the 5 old testimonials (the old site used lorem ipsum)
- Unsplash stock photos (deliberately not used)
